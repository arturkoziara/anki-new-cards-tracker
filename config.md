# New Cards Tracker

- **daily_target**: How many cards you aim to add each day (default `10`). The year grid and the streaks use this number.
- **show_on_deck_browser**: When `true`, the chart appears on Anki’s main screen.
- **included_deck_ids**: Deck IDs whose cards are counted (subdecks included). Empty `[]` counts all decks. Easiest to set via **Tools → New Cards Tracker Options…**.
